# Explorer 4 research register

[Published methods, places changed in the code and measured outcomes](RESEARCH_LINEAGE.md) · [Read this comparison on Homebrain](http://192.168.0.168:8030/simlab-media/reports/research-register-20261122/lineage.html)

**Research question.** Can a robot decide, from its own observations, that another robot can supply missing information, and does using that information improve the outcome enough to justify the request?

**Finding on 22 November 2026.** A ROSMASTER camera waypoint brought Tank to the correct simulated dock on 24/24 scenes. A missing-pose rule made 13 calls. Active search with Tank's own camera achieved the same score with zero calls and shorter median completion time. In the follow-up, a screen prevented active local docking in 12/12 screened development scenes while the donor-guided branch completed all 12. On all 24 follow-up development scenes, a sequential policy that searched first and requested a fresh observation only after a miss docked 24 times with 12 requests. The learned request policy has a stronger comparator for its held-out allocation study. ## What needs a person

**Current operator workload.** No new demonstrations are needed. The saved recordings, simulated expert, checkpoints and factory source suffice for the next software comparisons. On the original fixed-start experiment, a replay of one nominal validation trajectory missed the terminal hold duration by 0.10 seconds after float32 serialization. Preserve the historical result and diagnose the timing margin before using this replay as a reference for new training. [Replay trace](http://192.168.0.168:8030/simlab-media/reports/recorded-start-night/validation-action-replay.json)

**Before claiming physical performance.** The archived position audit compared 532 frame pairs and established zero episode-to-grid assignments. In 5,196 valid training frames, none matched the simulated look pose within both 2 cm and 5°. If no archived independent measurement fills this gap, place the cube at measured marks spanning the reachable area, record the scale, camera calibration, time and measured arm pose, and reserve different marks for checking projection error. This is a calibration session. Teleoperated training examples are required only for a missing motion or recovery identified after that check. Keep their parent sessions separate from independent test videos. [Position audit](http://192.168.0.168:8030/simlab-media/reports/recorded-start-night/cube-position-audit-20261121.json) · [Camera pose coverage](http://192.168.0.168:8030/simlab-media/reports/article-20261122/camera-pose-coverage.json)

**For the joint experiment.** Establish a shared measured target frame, supervise the mobile-base STOP and endpoint checks, and independently score the physical outcome. For a floor-to-table handover, measure both platforms' reach and table height first. The first two-robot approach experiment needs a marked target and visible/occluded starts. ## Publication decision

[Updated English draft on Homebrain (PDF)](http://192.168.0.168:8030/simlab-media/reports/research-register-20261122/peer-assisted-robots.pdf) · [Editable LaTeX, bibliography and figures](http://192.168.0.168:8030/simlab-media/reports/research-register-20261122/peer-assisted-robots-source.zip). The draft reports the completed paired camera intervention, active-search control, grasp ablation and screen-development evidence. It has not been submitted.

The earlier eight-page working manuscript, *What knowledge does a robot need to grasp an object?*, combines room simulations, simulated grasp comparisons and archived physical images. Its best supported result is the effect of target information on a grasp. It currently offers several diagnostics for a claim about selective peer assistance. Published physical systems already recruit peers or use a mobile camera to guide manipulation. A stronger contribution here is the measured value of asking at a particular time. [Physical viewpoint assistance](https://pmc.ncbi.nlm.nih.gov/articles/PMC12115303/) · [Proactive robot collaboration](https://doi.org/10.1038/s41467-026-72797-8)

* **Primary question.** Can a recipient use its own observations to choose when an independently sensed target pose from a peer improves completion at a fixed request cost? Test on unseen layouts with correct and degraded messages. Score the end task from a third source.
* **What to keep.** Use the 60 paired scenes as evidence that the recipient is sensitive to target information. Use the 40-scene request study, including its four discordant pairs, to motivate the need to distinguish a useful observation from a request that simply adds cost. The equal-budget control and negative human-data result deserve space.
* **What would change the conclusion.** A selective policy that makes fewer calls at comparable task success could be valuable if the equivalence or noninferiority margin is prespecified and the interval supports it. If correct messages beat shuffled packets but selective requests do no better than equal-budget random, report the value of communication and the failure of the proposed decision rule. A high number of software features provides no evidence about either claim.
* **Submission target checked on 22 November.** RSS 2027 accepts a first-stage extended abstract by **4 December 2026, 23:59 AoE (5 December, 14:59 Moscow)**. The limit is five content pages and one reference page. The call allows preliminary experiments with a fully specified scientific question and method. The blind PDF must stand alone without external website links. The invited second-stage deadline is 16 April 2027. All authors should check their OpenReview accounts now, particularly if institutional email is unavailable. [Official RSS call](https://roboticsconference.org/information/cfp/) · [Submission venue](https://openreview.net/group?id=roboticsfoundation.org/RSS/2027/Conference)

## Scope and reproducibility

This targeted review prioritized sources that release code, weights, protocols, or hardware-specific instructions and that change a decision on this fleet. It covers comparable mobile platforms and learning stacks from university, manufacturer and upstream projects. Benchmarks on different robots, task definitions, sensors and compute budgets retain their original scope. The primary links in each register distinguish direct library calls, local adaptations and candidate integrations. Uninspected repositories and unpublished negative results can exist.
