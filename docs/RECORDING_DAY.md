# Explorer 4.0 recording day

1. **Prepare one robot and its scene.** Set SO-101 on the table and keep Tank and ROSMASTER on the floor. Use consistent cubes and boxes for arm tasks. For mobile tasks, set out a visible target and mark the stopping zone. Clear the work area, disconnect the charger and keep the power switch within reach.
2. **Check fleet readiness.** Open [Fleet readiness](http://192.168.0.168:8030/recording/readiness) and inspect approval status, battery, sensor freshness, stream rates, clocks and disk space. A red row shows the action needed. Recording requires at least 8 GB of free storage. The readiness check applies to the selected robot.
3. **Run the hardware check.** Start the measurement step to read sensors, then move the robot yourself in its control panel. Confirm what you observed and save the result. A failed check can be repeated. Tank's panel is available immediately. Hand SO-101 control over from the service on port 8020. For ROSMASTER, use one control panel at a time.
4. **Create a recording series.** Open [Dataset collection](http://192.168.0.168:8030/recording/collect), pick a task and operator, and describe the layout. Use the existing layout when repeating a scene. Mobile tasks use the depth and lidar profile by default. Keep the profile consistent within a task.
5. **Record one demonstration per attempt.** Allow 3 to 120 seconds. Start recording and wait for the frame count to increase. Perform the task and mark success, failure or abort. F9, F10 and F11 control recording. Space stops motion. Stop before resetting the scene. The system reads the saved recording back automatically. A warning keeps the recording available for review and excludes it from training until resolved.
6. **Review one or two videos after each series.** Aim for ten distinct layouts and five usable successful demonstrations per layout, per task. The progress counter counts recordings that pass the checks. Repeating a layout under a different name creates another attempt in the same group.
7. **Stop, back up and turn off the robot.** Use the backup action on Fleet Readiness. Set an external destination or provide a drive with an `explorer3-backup` directory. When no external destination is available, the local backup contains the SQLite copy and hash manifest only. Return control to the previous SO-101 service or the Hiwonder app if needed. Turn the robot off before charging. [Tank charging instructions](TANK.md)
